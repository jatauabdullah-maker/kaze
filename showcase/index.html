Inspect

Kaze reads the source first - episodes and release groups for anime, formats and sizes for video.

Choose

You pick from what actually exists, not a fixed dropdown that guesses.

Download

Files land in a folder you choose, straight from your connection. Nothing passes through a Kaze server.

Setup

Video grabber

  1. Open kaze-downloader.vercel.app
  2. Download the server zip and unzip it anywhere
  3. Run Kaze.bat, pick 1, wait for DONE
  4. Pick 3 for auto-start (recommended), or 2 to start now
  5. Hit Check my PC on the site and paste a link

Anime extension

  1. Open chrome://extensions and turn on Developer mode
  2. Load unpacked, choose the Kaze extension folder
  3. Click the Kaze icon to open the full-page app
  4. Search, pick episodes, inspect sources, choose a folder
  5. Download - your files are saved locally

Help

Something broke

Sources change often. For the video grabber, run Kaze.bat and pick 1 - it re-downloads the latest engine and repairs components.

Where do files go?

Video lands in Downloads\KazeVideos. Anime goes into whichever folder you picked when you started the job.

Is it private?

Yes. Both tools download directly from your connection to your disk. The website is only the remote control for the local server.
