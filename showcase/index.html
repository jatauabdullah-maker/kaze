GET GOING

Setup in a minute

Video grabber

  1. Open kaze-downloader.vercel.app
  2. Download the server zip and unzip it anywhere
  3. Run Kaze.bat, pick 1, wait for DONE
  4. Pick 2 to start the server
  5. Hit Check my PC on the site and paste a link

Anime extension

Download extension
  1. Download and unzip the extension above
  2. Open chrome://extensions and turn on Developer mode
  3. Load unpacked, choose the Kaze extension folder
  4. Click the Kaze icon to open the full-page app
  5. Search, pick episodes, inspect sources, choose a folder
  6. Download — your files are saved locally
